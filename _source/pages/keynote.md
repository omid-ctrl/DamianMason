## Defects observed on the live page
- **No meta description and no og:description.** `<head>` has `og:title` ("Keynote") and `og:image` but no
  description of any kind — social shares and SERP snippets will be auto-generated.
- **Missing background image (404).** `.et_pb_section_2` requests
  `https://damianmason.wpengine.com/wp-content/uploads/2023/02/life-coach-03.jpg`, which is **not in the
  mirror**. The filename is a **Divi "Life Coach" premade-layout demo asset** left behind from the original
  template — this section was never re-photographed.
- **wpengine.com staging URLs in production.** Both inline images, all three MP4 sources, the parallax
  background, the hero column background, and the missing `life-coach-03.jpg` all resolve to
  `https://damianmason.wpengine.com/...`.
- **Squarespace markup pasted into all three testimonials.** Each `et_pb_testimonial` body contains a
  leftover Squarespace block: `<div class="sqs-block quote-block sqs-block-quote null sqs-col-10 span-10
  float float-right" data-block-type="31" id="block-yui_3_17_2_1_1527781697578_155324">` (and `…_127177`,
  `…_115760`) wrapping `<figure class="block-animation-none"><figcaption class="source">`. The site was
  migrated from Squarespace and the reviews were copy-pasted as raw HTML. **The attribution is therefore
  inside `<figcaption>`, nested inside the quote body**, while Divi's own
  `<p class="et_pb_testimonial_meta">` author field is left empty on all three.
- **Broken punctuation in testimonial 1.** The quote renders as `“I would highly recommend working with
  Damian!” –` — a trailing en dash with nothing after it, presumably where a name once was (the actual name
  appears below in the Squarespace figcaption).
- **Testimonial 3 has a stray empty paragraph** after the figcaption: `<p><span></span></p>`.
- **Empty FAQ answer.** `WHAT ARE THE TECHNOLOGY REQUIREMENTS?` (`et_pb_toggle_9`) has
  `<div class="et_pb_toggle_content clearfix"></div>` — the toggle opens onto nothing. (Home's equivalent
  question **does** have an answer: "Refer to Damian's AV/and Room Setup Requirements." — so the two pages are
  inconsistent.)
- **Both inline images have empty alt text**, and one of them (`Screenshot-2023-04-20-at-3.38.16-PM.png`) is a
  **macOS screenshot used as marketing imagery**.
- **Heading order violation.** `<h2>DAMIAN MASON</h2>` and `<h6>Motivating and inspiring…</h6>` both appear
  **before** the page's only `<h1>`, inside the same text module. The page then uses H2 for four different
  purposes (eyebrow, section titles, bio title, "Reviews" column title).
- **Two H2s in one section** (section 7: the bio title and "Reviews").
- **Trailing space inside a heading.** `<h3>Food Waste </h3>`.
- **Bullet lists faked with `•` + `<br />`.** All four credential blurbs use literal U+2022 characters and
  line breaks instead of `<ul><li>`, so they are not announced as lists.
- **Videos have no poster frames, no captions, no transcripts.** Three raw `<video controls>` elements with a
  single MP4 source each, no `poster`, no `<track>`, no `preload` hint — a mobile visitor sees three black
  rectangles.
- **A whole section with zero content.** `et_pb_section_5` is a parallax image band containing no rows,
  columns or modules.
- **Content divergence with the home page.** The keynote copy of the program description says
  "forward-looking … fast-paced, humor-infused … feel-good facts … Beginning **in** 2023"; the home page FAQ
  copy of the same text says "forward looking … fast paced, humor infused … feel good facts … Beginning 2023".
  Likewise "HOW DO YOU MANAGE BOOKING TRAVEL & TRAVEL EXPENSES?" (keynote) vs.
  "HOW DO YOU MANAGE BOOKING **AND** TRAVEL AND TRAVEL EXPENSES?" (home). Two sources of truth, both live.
- **Double spaces after sentence periods throughout** the bio, the blockquote, and the FAQ answers, plus
  trailing spaces at the end of several answers — pasted from a word processor.
- **Mixed apostrophe styles.** Curly (U+2019) everywhere except the "Sign up for Damian's email list" button
  label, which uses `&#039;` (U+0027).
- **Internal link opens in a new tab.** "Sign up for Damian's email list" -> `/join-the-conversation/` with
  `target="_blank"` (and no `rel="noopener"` on that anchor).
- **Leftover Gmail tracking attribute.** The YouTube channel link in the FAQ carries

## Defects observed on the live page
- **Wrong show's SoundCloud.** The "Follow on SoundCloud" icon points at `https://soundcloud.com/thebusinessofagriculture` — that is Damian's *other* podcast. Every other link on this page correctly targets `soundcloud.com/dobusinessbetter`. Should be `https://soundcloud.com/dobusinessbetter`.
- **Empty href placeholder #1:** "Follow on Youtube" social icon -> `href='#'`.
- **Empty href placeholder #2:** "Follow on iTunes" social icon -> `href='#'`. The show is presumably on Apple Podcasts; the link was never filled in.
- **Duplicate H1.** Two `<h1>` elements on one page: "Do Business Better Podcast" and "Latest 3 Episodes". "Latest 3 Episodes" is a section label, not a page title.
- **Broken heading hierarchy.** Order down the page is H1 → H3 → (H2 "Success!") → H4 → H2 → H1 → H3 ×3 → H2 → H4. The "Latest Episode" eyebrow is an H4 sitting above an H2 episode title.
- **Hidden H2 in the DOM.** `<h2>Success!</h2>` lives in the newsletter's success container and is present in the markup at all times.
- **Duplicated content block.** The entire "Latest Episode" section (title + full paragraph + SoundCloud link) repeats verbatim as the first item of "Latest 3 Episodes" immediately below it. Same copy twice within one screen.
- **Squarespace markup pasted into WordPress.** The "Latest Episode" description is wrapped in `<div class="row sqs-row">` > `<div class="col sqs-col-9 span-9">` > `<div class="sqs-block html-block sqs-block-html" data-block-type="2" id="block-yui_3_17_2_1_1681826407359_10726">` > `<div class="sqs-block-content">`. Squarespace grid classes and a YUI-generated block ID, inside a Divi module.
- **SoundCloud UI markup pasted into WordPress.** The "Start Listening Today!" paragraph is wrapped in `infoStats__description` / `truncatedUserDescription m-collapsed` / `truncatedUserDescription__wrapper` / `truncatedUserDescription__content` (nested twice) plus a stray empty `web-profiles` / `sc-truncate` pair. `m-collapsed` is SoundCloud's *truncated* state class.
- **"Latest 3 Episodes" is not the latest three.** Listed episodes are #144, #142, #141 — #143 is missing.
- **Stale content.** Page `dateModified` is 2023-06-20; the newest episode shown is #144 from that period. Hardcoded, so it has not moved since.
- **33 MB self-hosted MP3.** `VisionTechMgmt.mp3` is served from `wp-content/uploads` at 33 MB with `preload="none"`. Enormous for a web page asset.
- **Empty alt on the primary image.** `DBB-LOGO.png` — the show's identity art and the page's og:image / schema `primaryImageOfPage` — has `alt=""`.
- **Empty layout column.** The final row's two-thirds column renders with `et_pb_column_empty` and no content.
- **Contact email is not clickable.** `damianmasonoffice@gmail.com` is plain `<p>` text in this section (no `mailto:`).
- **Newsletter form has no `action`.** `<form method="post">` with no action attribute; relies entirely on Divi's Mailchimp AJAX handler, and the submit control is an `<a href="#">` rather than a `<button type="submit">` — the form is unusable with JS disabled and not keyboard/AT-correct.
- **Hidden form label.** `<label for="et_pb_signup_email" style="display: none;">Email</label>` — inline-hidden rather than visually-hidden, so the field is placeholder-only.
- **Mailchimp list ID exposed in markup.** `et_pb_signup_list_id=6456b31ef4` and `et_pb_signup_account_name=Damian Mason` are in plain HTML.
- **Copy typo preserved:** "in his mid 50’s no less!" — apostrophe-s on a decade (appears twice, once in each duplicate of the Dave Swain paragraph).
- **Copy inconsistency preserved:** the podcast description reads "self employed striver" (unhyphenated) while the same sentence style elsewhere uses hyphenated compounds.
- **Double-encoded UTM tails.** Two episode links carry `utm_content=https%253A%252F%252F...` — a double-encoded URL inside a query string, straight from the SoundCloud share widget.
- **Inconsistent underline markup** between episode links (span-inside-anchor vs anchor-inside-span).
- **Site-wide, visible on this page:** header nav "Speaking", "Podcasts" and "Media" top-level items all have `href=""` (empty). Header logo and every footer link resolve to `damianmason.wpengine.com` (staging host) or `?page_id=NNN` query URLs rather than the live `damianmason.com` pretty permalinks; the footer "Home" link is plain `http://DamianMason.com` (no HTTPS).
